# HexaCraft

**Construis, explore et fais tout exploser dans un monde fait d'hexagones.**

HexaCraft est un jeu bac à sable inspiré de Minecraft, où chaque bloc est un prisme hexagonal. Chaque seed génère un monde unique : forêts, déserts de cactus, plaines enneigées, océans, et volcans où coule la lave. Le ciel change au fil des jours : le soleil se lève, la lune passe par ses phases et des nuages en hexagones dérivent avec le vent, en projetant leur ombre sur le paysage.

- **Survie** : bois, cailloux, charbon, fer et voltite, outils, four, coffre, établi.
- **Nature vivante** : les arbres repoussent à partir de leurs pousses, l'herbe reprend la terre.
- **Circuits** : la voltite conduit le courant ; fils, leviers et torches d'énergie allument des TNT ou mettent des machines en marche.
- **Physique** : la super colle assemble des blocs en objets que la main gravitationnelle déplace et que le bloc physique fait avancer. Les Hexacarts filent sur les rails.
- **Explosions** : TNT, Big TNT, TNT 200… et la TNT 1000, qui rase tout sur 130 blocs.
- **Multijoueur**, en créatif ou en survie.

## Télécharger

Va dans l'onglet **[Releases](https://github.com/MSpace94/Hexecraft/releases)** et télécharge `HexaCraft-Setup-0.8.0.exe`, puis lance-le.

Windows 10 / 11, 64 bits. Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* › *Exécuter quand même*.

## Commandes principales

| Touche | Action |
|---|---|
| Z Q S D | Se déplacer |
| Espace | Sauter (double appui : voler) |
| Clic gauche / droit | Casser / poser, utiliser |
| E | Inventaire |
| T | Chat (`/` : commande) |
| F5 | Changer de vue |
| Échap | Menu |
